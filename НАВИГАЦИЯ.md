## 🎓 Структура кода (bot.py):

```python
# Функции хранения данных:
load_allowed()              # Загрузить список пользователей
save_allowed()              # Сохранить список пользователей

# API интеграция:
datagrab_check_pdf()        # Отправить PDF в datagrab
format_check_result()       # Форматировать ответ

# Проверки:
is_owner()                  # Проверка владельца

# Команды бота:
start()                     # /start
handle_document()           # PDF файл
allow_command()             # /allow
revoke_command()            # /revoke
list_allowed_command()      # /list_allowed

# Запуск:
main()                      # Инициализация и запуск
```

## 📦 Зависимости (requirements.txt):
