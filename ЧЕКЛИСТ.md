# ✅ Чек-лист запуска бота

## 🔒 Безопасность (КРИТИЧНО!)

- [ ] **ОТОЗВАТЬ старый токен**: @BotFather → `/revoke` → выбрать бота
- [ ] **Создать новый токен**: @BotFather → `/newbot` или `/token`
- [ ] **Никогда не публиковать** токены/ключи в чатах/git

## 📦 Установка

- [ ] Открыть терминал
- [ ] Перейти в папку: `cd /Users/step/Desktop/bot_helper`
- [ ] Создать venv: `python -m venv .venv`
- [ ] Активировать: `source .venv/bin/activate`
- [ ] Установить зависимости: `pip install -r requirements.txt`

## ⚙️ Настройка

- [ ] Скопировать шаблон: `cp .env.example .env`
- [ ] Открыть редактор: `nano .env` (или другой)
- [ ] **BOT_TOKEN**: вставить новый токен от @BotFather
- [ ] **DATAGRAB_API_KEY**: вставить ключ от bankpdf.ru
- [ ] **OWNER_ID**: узнать в @userinfobot и вставить
- [ ] **DATAGRAB_ENDPOINT**: оставить `https://api.datagrab.ru/upload.php`
- [ ] Сохранить файл

### Пример правильного .env:

```bash
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz123456789
DATAGRAB_API_KEY=abcdef123456789
DATAGRAB_ENDPOINT=https://api.datagrab.ru/upload.php
OWNER_ID=123456789
```

## 🚀 Запуск

- [ ] В терминале: `export $(cat .env | xargs)`
- [ ] Запустить: `python bot.py`
- [ ] Увидеть: `INFO:__main__:Starting bot...`
- [ ] ✅ Бот работает!

## 🔧 Если что-то не работает

### Бот не запускается
```bash
# Проверить .env
cat .env

# Проверить токен
echo $BOT_TOKEN

# Переустановить зависимости
pip install --upgrade -r requirements.txt
```

### "Ключ API указан неверно"
- [ ] Проверить DATAGRAB_API_KEY в .env
- [ ] Проверить оплату на bankpdf.ru
- [ ] Попробовать резервный сервер: `DATAGRAB_ENDPOINT=https://api2.datagrab.ru/upload.php`

### "У вас нет доступа"
- [ ] Проверить OWNER_ID (должен совпадать с вашим)
- [ ] Убедиться, что вы добавили себя: `/allow ваш_id`
- [ ] Проверить allowed.json: `cat allowed.json`

### Бот не отвечает
- [ ] Проверить, что бот запущен (в терминале)
- [ ] Проверить BOT_TOKEN (создать новый)
- [ ] Проверить интернет
- [ ] Посмотреть логи в терминале
