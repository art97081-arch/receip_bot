## 🎯 Функционал бота:

### Для владельца (OWNER_ID):
- `/start` — справка
- `/allow <user_id>` — добавить пользователя
- `/revoke <user_id>` — удалить пользователя
- `/list_allowed` — список разрешенных
- Отправить PDF — проверить чек

### Для разрешенных пользователей:
- `/start` — справка
- Отправить PDF — проверить чек

### Без доступа:
- `/start` — справка
- Отправить PDF — получить сообщение "нет доступа"

## 🔧 Интеграция с datagrab API:

✅ **Реализовано согласно документации:**

1. Эндпоинт: `POST https://api.datagrab.ru/upload.php?key={api_key}`
2. Формат: multipart/form-data с полем `file`
3. Обработка всех ответов:
   - `forbidden` — неверный ключ
   - `unpaid` — истек период
   - `error` — ошибка обработки
   - `unrec` — не распознан
   - `fake` — поддельный
   - `mod` — виртуальный принтер
   - `size` — неверный размер
   - Успешный результат с полными данными чека

4. Парсинг данных чека (check_data):
   - Отправитель (sender_name, sender_acc)
   - Получатель (remitte_name, remitte_acc, remitte_tel)
   - Сумма, статус, время платежа
   - ID документа
   
5. Красивое форматирование:
   - Эмодзи для статусов (✅ ❌ ⚠️)
   - Структурированный вывод
   - Перевод timestamp в читаемую дату
   - Скрытие части номеров счетов (****4878)

## 🚀 Запуск за 3 команды:

```bash
# 1. Установка
python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt

# 2. Настройка (создайте .env и заполните)
cp .env.example .env
nano .env

# 3. Запуск
export $(cat .env | xargs) && python bot.py
```
